# Engineering

Skills for daily code work.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[tdd](./tdd/SKILL.md)**: Test-driven development with a red-green-refactor loop. Builds features or fixes bugs one vertical slice at a time. From [mattpocock/skills](https://github.com/mattpocock/skills).
- **[code-review](./code-review/SKILL.md)**: Two-axis review of the diff since a fixed point: Standards (does it follow the repo's coding standards, plus a Fowler smell baseline?) and Spec (does it faithfully implement the originating issue/spec?), run as parallel sub-agents. From [mattpocock/skills](https://github.com/mattpocock/skills).
